# Research Playbook

## Goal

Provide fast, reliable, and cited guidance for Frappe decisions.

## Triage Questions

Before searching, clarify:

- what decision must be made now?
- what are acceptable tradeoffs?
- what version(s) are in scope?

## Evidence Ladder

Highest trust:

1. official docs
2. current source code behavior
3. release/changelog notes
4. forum threads

## Decision Memo Template

- `question`
- `context`
- `findings`
- `recommended_action`
- `why_not_other_options`
- `sources`

## Common Failure Modes

- applying outdated forum advice to newer versions
- skipping source validation for docs ambiguities
- ignoring app-specific custom hook overrides
